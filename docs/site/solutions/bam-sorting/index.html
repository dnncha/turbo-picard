Parallel BAM sort and k-way merge performance.

PR #76 overhauled Turbo Picard’s external sorter and multi-file merger to reuse record buffers, eliminate redundant header/order checks on pre-sorted streams, use tournament-tree selection during k-way merges, and wire multi-threaded BGZF compression on spill runs and final outputs:

  • SortSam (coordinate, 1.2M reads on Apple M5): 0.520 s — 2.35x faster than prior main (1.223 s) and 4.32x faster than Picard 3.4.0 (2.245 s).
  • SortSam (queryname, 1.2M reads on Apple M5): 0.415 s — 2.64x faster than prior main (1.096 s) and 4.63x faster than Picard 3.4.0 (1.923 s).
  • MergeSamFiles (4-way 1.2M reads on Apple M5): 0.166 s — 1.74x faster than prior main (0.288 s), 6.58x faster than Picard 3.4.0 (1.090 s), and matching samtools merge -@8 (0.154 s) while preserving Picard headers and tie order.
  • External sort core: Reduced peak buffer allocation by 23.5% on random 262k synthetic runs with bit-identical sorted output.

Coordinate and queryname order solve different problems.

Coordinate sorting enables indexed region queries (CREATE_INDEX=true) and variant calling. Queryname sorting groups mates together for duplicate marking, alignment post-processing, and direct-stream FASTQ export. Turbo Picard’s SortSam implements both orders across SAM, BAM, and CRAM (pass REFERENCE_SEQUENCE for CRAM) and verifies actual record ordering instead of blindly trusting the @HD header.

Balance memory buffers and scratch throughput.

When sorted runs spill to disk, MAX_RECORDS_IN_RAM bounds the in-memory run size while TMP_DIR selects local NVMe or scratch storage. Tune reader/writer threads for large BAM/CRAM transfers using TURBO_PICARD_THREADS or role-specific variables.

An explicit coordinate-sorting trial.

Shell example
run_dir="$(mktemp -d)"
mkdir "$run_dir/scratch"
TURBO_PICARD_REQUIRE_NATIVE=1 \
  turbo-picard SortSam \
  I=/data/unsorted.bam O="$run_dir/coordinate.bam" \
  SORT_ORDER=coordinate TMP_DIR="$run_dir/scratch" \
  MAX_RECORDS_IN_RAM=100000 CREATE_INDEX=true CREATE_MD5_FILE=true
printf 'Sorted outputs retained in %s\n' "$run_dir"

For queryname sorting, set SORT_ORDER=queryname and omit CREATE_INDEX.
