First target shortlist
======================

Use this page when you want an ordered list of the first places to try, rather
than a general discussion of channels.

1. Local team first
-------------------

Start here when the result is still local and the immediate workflow team has
not seen it yet.

Use:

* ``packaging/outreach/slack-message.md``
* ``packaging/outreach/one-page-brief.md``

2. Workflow repository discussion
---------------------------------

Use this next when you already know the exact pipeline repository that should
care.

Use:

* ``packaging/outreach/workflow-repo-discussion.md``
* :doc:`propose-it-in-a-workflow-repo`

3. nf-core Slack
----------------

Use this when the result is relevant to ``nf-core`` maintainers or users and
you want feedback before or alongside a more concrete module or workflow
proposal.

Official community page:

* `Join nf-core <https://nf-co.re/join>`_

Repo file:

* ``packaging/outreach/nf-core-slack.md``

4. Seqera Community / Nextflow forum
------------------------------------

Use this when the result is relevant to a broader ``Nextflow`` audience beyond
one repository.

Official community pages:

* `Seqera Community <https://community.seqera.io/>`_
* `Nextflow docs community section <https://docs.seqera.io/nextflow/>`_

Repo file:

* ``packaging/outreach/seqera-community.md``

How to pick between 3 and 4
---------------------------

Choose ``nf-core`` Slack first when:

* the likely adopters are ``nf-core`` pipeline or module maintainers;
* the result fits the ``nf-core`` ecosystem directly.

Choose Seqera Community first when:

* the likely adopters are broader ``Nextflow`` users;
* the result is useful even outside ``nf-core``.
