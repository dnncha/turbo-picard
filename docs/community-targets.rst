Community targets
=================

Use this page when you already have a narrow ``turbo-picard`` result and want
to choose a concrete place where real workflow users are likely to see it.

nf-core Slack
-------------

Good target when:

* the result is relevant to ``nf-core`` users or maintainers;
* you want feedback before or alongside a module or workflow proposal;
* the message is about a real pipeline step, not a broad tool announcement.

Best shape:

* name the command that was tested;
* name the workflow context;
* point people to the first-trial path rather than claiming a full replacement.

Seqera Community / Nextflow forum
---------------------------------

Good target when:

* the audience is broader than one repo;
* the topic is useful to ``Nextflow`` users even outside ``nf-core``;
* you want a discussion that stays searchable and attached to a workflow community.

Best shape:

* focus on the narrow command-level result;
* explain why the command matters in a real pipeline;
* link to the evaluation path and workflow examples.

Workflow repository discussion or PR
------------------------------------

Good target when:

* you already know the exact workflow repo that should change;
* the command boundary is clear;
* another maintainer can inspect the evidence and review a narrow proposal.

Best shape:

* keep the proposal scoped to one command;
* make fallback or rollback visible;
* link to the comparison and maintainer-checklist pages.

Internal platform or lab channel
--------------------------------

Good target when:

* the team still needs local alignment first;
* the result is useful, but not yet ready for a wider public proposal;
* you want to confirm the command choice before opening external discussion.

Best shape:

* short message;
* exact command name;
* one sentence on what was compared;
* one next step.

How to choose
-------------

If the result is:

* specific to one pipeline repo, start with the workflow repo;
* relevant to many ``Nextflow`` users, consider Seqera Community;
* especially relevant to ``nf-core`` users or module maintainers, consider
  ``nf-core`` Slack first;
* still local and not yet ready for public review, start inside the team.
