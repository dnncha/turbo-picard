Launch bundle
=============

Use this page when you want the smallest complete outreach pack for the first
real external pass.

Recommended first bundle
------------------------

For one narrow command-level result, the smallest useful bundle is:

1. one evidence summary;
2. one maintainer-facing checklist;
3. one channel-shaped message;
4. one workflow-specific link for follow-up.

What to use
-----------

Start here:

* :doc:`workflow-maintainer-checklist`
* :doc:`share-results`
* :doc:`channel-specific-examples`
* :doc:`community-targets`
* :doc:`first-target-shortlist`

Then use these repo files directly:

* ``packaging/outreach/nf-core-slack.md``
* ``packaging/outreach/seqera-community.md``
* ``packaging/outreach/workflow-repo-discussion.md``
* ``packaging/outreach/team-review-template.md``

Suggested order
---------------

1. write down the exact command-level result;
2. decide whether the next move is local, repo-specific, or broader;
3. choose the matching channel file;
4. link readers to the first-trial and proposal docs;
5. keep the claim narrow enough that another maintainer can review it quickly.

What success looks like
-----------------------

The first pass is successful if:

* the audience understands which command was tested;
* the workflow context is obvious;
* the next step is clear;
* nobody has to guess whether this is claiming a full Picard replacement.

What this page is for
---------------------

This page is not another explanation of the product. It is the handoff page
for taking one good result and turning it into a small, defensible outreach
bundle.
