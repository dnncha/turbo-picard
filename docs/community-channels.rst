Community channels
==================

Use this page when a ``turbo-picard`` result is ready to leave your local repo
or team and the question is where it should go next.

Internal team chat
------------------

Use this first when:

* the immediate workflow team still has not seen the result;
* you want quick feedback on whether the command choice makes sense;
* the next step is still local review rather than a public proposal.

Workflow or module PR
---------------------

Use this when:

* the Picard step already lives in a workflow repository;
* the comparison evidence exists;
* the proposed change is intentionally narrow.

This is the highest-signal channel when you already know the exact workflow
boundary that should change.

GitHub discussion
-----------------

Use this when:

* maintainers need to agree that the trial is worth doing before reviewing code;
* the result is useful in one repo, but not yet ready as a concrete PR;
* you want the discussion to stay attached to the workflow repository.

Community post
--------------

Use this when:

* the result is useful outside one repository;
* you want other Picard users to see the first-trial path;
* the message is still about one or two commands, not a blanket replacement story.

Release notes or changelog
--------------------------

Use this when:

* the command-level result is already accepted;
* existing users of the workflow need to know the option exists;
* the message should stay short and factual.

How to choose quickly
---------------------

Ask three questions:

1. Is the audience local to one workflow repo or broader than that?
2. Is the next step discussion, review of code, or just awareness?
3. Do you already have command-level evidence that another maintainer can inspect?

If the answer is still unclear:

* use :doc:`workflow-maintainer-checklist` for the go/no-go screen;
* use :doc:`propose-it-in-a-workflow-repo` for repo-specific proposals;
* use :doc:`message-examples` when you need wording fast.
* use :doc:`community-targets` for concrete workflow-community venues.
