# Turbo Picard v0.1.22

This patch release restores full PyPI publication across all four wheel
platforms (Linux x86_64, Linux ARM64 `manylinux_2_28`, macOS Intel, and Apple
Silicon) plus the source distribution, carrying forward all scientific parity,
GATK4 flag, and MCP `verify` improvements from `v0.1.21`.

## Packaging fixes

- **Native Linux ARM64 PyPI wheels (#107).** Switched the `linux-aarch64` job in
  `.github/workflows/publish-pypi.yml` from `manylinux2014` cross-compilation
  (whose GCC 4.8 failed compiling `libdeflate`) to native `ubuntu-24.04-arm`
  with `manylinux_2_28`, and added a native ARM64 install smoke test.
- **Linux x86_64 smoke-test wheel glob (#107).** Updated `Validate distributions`
  to match `maturin`'s `manylinux2014_x86_64.manylinux_2_17_x86_64` tag ordering.

## Highlights carried from v0.1.21

- Exact genome-scale `MarkDuplicates` optical duplicate and SAM columns 1-11
  parity against Picard 3.4.0 on 30x GRCh38 WGS HG02675 (`ERR3242389`,
  740,367,510 records; Host B build `93216217`: 43m 07s / 354 MB RSS) and chr21
  `DT`/`DS`/`DI`/`PG` tag parity (#87, #88).
- 30x WGS `CollectWgsMetrics` parity at 5m 08s / 352 MB RSS vs Picard's
  2h 13m 55s / 4.0 GB RSS (#89).
- GATK4 `--kebab-case` and bare boolean flags plus the isolated `turbo-picard mcp`
  `verify` tool (#93, #95).

See `CHANGELOG.md` for the full list.
