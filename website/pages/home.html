Current boundaries

The questions worth asking.

Can this replace all of Picard?

No. This is not a full Picard suite. Some commands have scoped native support; others require upstream Picard. Unsupported commands or options can use configured or detected fallback. Check the exact command before switching.

Will it be faster on my whole genome?

That is a measurement to make, not a promise to inherit. Compression, storage, coverage, duplicate families and options change the result. Compare your own input and keep the whole task’s time and resource use.

Do I need a GPU, Java or an AI service?

Native paths run on the CPU without Java or an AI service. Java is needed when you deliberately use upstream Picard or run a Picard comparison. No production GPU backend is enabled in this release.

What about metrics, charts and reproducibility?

Metrics text is the parity target for supported collectors. Lightweight PDF summaries are not a reproduction of Picard’s full chart rendering. Pin a release, retain the exact options and compare the outputs your downstream tasks consume.
