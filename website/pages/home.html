Current boundaries

Honest answers before you adopt.

Can this replace all of Picard?

No. This is not a full Picard suite: 41 commands have native or scoped-native Rust implementations and 86 require upstream Picard fallback. Check your exact command and options first.

How does it compare to Riker, FastDup, and samtools?

Turbo Picard is the only Rust tool keeping Picard’s CLI and Picard-identical outputs across both duplicate marking and QC. On 4x GRCh38 WGS QC, it matched Picard 3.5.0 while running ~46x faster than Picard and 1.3x faster with 4.0x less RAM than riker wgs. On 1-CPU MarkDuplicates (paired-600k), it beat Picard (5.15x faster, 11.2x less RAM), FastDup (4.1x less RAM), and the samtools markdup pipeline (1.88x faster). Read full comparison →

Do I need Java or a GPU?

Native commands run on the CPU with no Java or GPU required. Keep Java + picard.jar available only if you want fallback for unsupported commands or to run side-by-side comparisons.

What about PDF charts and reproducibility?

Metrics text and histograms match Picard’s contract; chart sidecars are lightweight PDF summaries rather than full R plots. Pin versions via PyPI, Docker, or Bioconda and verify representative data before rollout.
