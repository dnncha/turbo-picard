# Outreach kit

This directory holds short, reusable text for people who have already tried
`turbo-picard` and want to bring it to a team, workflow group, or community
channel without writing the pitch from scratch.

Files:

- `slack-message.md`: short internal message for a lab or pipeline channel
- `email-blurb.md`: slightly longer note for a workflow owner or platform team
- `release-note.md`: release or changelog snippet
- `module-pr-note.md`: short note for a workflow or module pull request
- `evaluation-checklist.md`: compact internal checklist for deciding whether to run a first trial
- `channel-map.md`: quick guide to which outreach template fits which venue
- `launch-plan.md`: simple sequence for taking an evaluation into wider visibility
- `community-post.md`: reusable community-facing post
- `github-discussion.md`: short note for a GitHub discussion or issue thread
- `nf-core-slack.md`: ready-to-post short note for nf-core Slack
- `seqera-community.md`: ready-to-post short note for Seqera Community / Nextflow discussion
- `workflow-repo-discussion.md`: ready-to-post short note for a workflow repository discussion
- `objections.md`: short answers to common adoption questions and objections
- `team-review-template.md`: short template for recording the outcome of a first trial
- `first-pass-bundle.md`: smallest practical set of files for the first real external pass
- `one-page-brief.md`: compact forwardable overview of what the package is and how to trial it honestly
- `outreach-tracker.md`: simple tracker for the first real external pass
- `follow-up-playbook.md`: simple guide for handling the first replies after outreach starts

Use these only after you have some command-level evidence from your own data or
from the checked-in public evidence. They are meant to speed up communication,
not replace evaluation.
