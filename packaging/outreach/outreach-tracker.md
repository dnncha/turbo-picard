# Outreach tracker

Use this to track the first real external pass.

| Channel | Audience | File | Status | Link / note |
| --- | --- | --- | --- | --- |
| Internal team chat | local workflow team | `slack-message.md` or `one-page-brief.md` | todo | |
| nf-core Slack | nf-core users / maintainers | `nf-core-slack.md` | todo | |
| Seqera Community | Nextflow users | `seqera-community.md` | todo | |
| Workflow repo discussion | one target pipeline repo | `workflow-repo-discussion.md` | todo | |
| Follow-up PR | same repo if discussion lands well | `module-pr-note.md` | todo | |

## Status values

- `todo`
- `drafted`
- `posted`
- `follow-up needed`
- `done`
