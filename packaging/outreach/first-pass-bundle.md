# First-pass outreach bundle

Use this when one narrow `turbo-picard` result is ready and you want the
smallest practical set of files for the first real external pass.

## Minimum bundle

1. `team-review-template.md`
2. one channel-specific post:
   - `nf-core-slack.md`
   - `seqera-community.md`
   - `workflow-repo-discussion.md`
3. `channel-map.md`
4. `launch-plan.md`
5. `one-page-brief.md` if someone needs a compact forwardable overview

## Order

1. Write down the exact command-level result in `team-review-template.md`.
2. Pick the audience with `channel-map.md`.
3. Start from the matching ready-to-post file.
4. Use `launch-plan.md` if you need the order for wider follow-up.
5. Track what has been drafted or posted in `outreach-tracker.md`.
6. Use `follow-up-playbook.md` once replies start coming back.

## Keep the claim narrow

Lead with:

- which command was tested
- what workflow shape it fits
- what was compared
- what the next step is

Do not lead with:

- claims about replacing all of Picard
- speed numbers with no workflow context
- toy examples that do not resemble the real workflow
