# Release note snippet

Added evaluation material for `turbo-picard`, a Rust implementation of selected
Picard commands.

- starter examples for `WDL`, `Nextflow`, and `Snakemake`
- command-selection guidance for choosing a sensible first Picard step to test
- a small one-command trial bundle for side-by-side evaluation on representative data

The intended rollout is still one command at a time with output comparison, not
a blanket claim that every Picard workflow is ready to switch unchanged.
